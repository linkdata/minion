# caveman

> Modified for Minion: this README describes the bundled skill.

Caveman keeps technical facts while cutting filler from replies. It stays active until the user says `stop caveman` or `normal mode`.

Use `/caveman` to activate it. Use `/caveman status` to check the current mode. See [SKILL.md](SKILL.md) for the response rules.

The bundled `LICENSING.md` and `NOTICE` are upstream legal records; their paths refer to the Caveman repository at the commit recorded in `.minion-install.json`.
